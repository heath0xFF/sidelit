# A quieter place to think

This is a sample document for **Sidelit**. Click this paragraph and start writing. The page is the editor.

## Beside your agent

Keep Sidelit open while a terminal agent works on these files. When you have no unsaved edits, its changes appear here. When you have a draft, Sidelit keeps both versions.

> Your Markdown stays in ordinary files. Nothing needs an account or a connection.

### Try a few things

- [x] Open a document from the terminal
- [ ] Edit a sentence and press **⌘S**
- [ ] Switch to Source with **⌘\\**
- [ ] Change this file from another editor

1. Read the draft.
2. Make it clearer.
3. Save only when you are ready.

You can use *emphasis*, **strong text**, ~~strikethrough~~, and `inline code`.

```rust
fn main() {
    println!("Markdown, beside your work.");
}
```

## The small details

| Mode | Best for |
| :--- | :--- |
| Rendered | Reading, writing, and revising |
| Source | Exact syntax and unsupported extensions |
| Compare | Keeping an external change and a draft in view |
